## Перелік функціональних вимог (FR)

| ID | Функціональна вимога | Пріоритет (MoSCoW) |
| :--- | :--- | :--- |
| **FR-01** | Система має дозволяти користувачу здійснювати пошук інструментів за назвою через пошуковий рядок. | Must (Обов'язково) |
| **FR-02** | Система має фільтрувати ресурси за категоріями (Design, Dev, Productivity). | Must (Обов'язково) |
| **FR-03** | Система має забезпечувати авторизацію користувачів через сторонні сервіси (Google/GitHub). | Must (Обов'язково) |
| **FR-04** | Система має дозволяти авторизованому користувачу додавати інструменти в особистий список «Обране». | Should (Бажано) |
| **FR-05** | Система має дозволяти авторизованому користувачу пропонувати нові ресурси через спеціальну форму. | Should (Бажано) |
| **FR-06** | Система має надавати адміністратору інтерфейс для модерації (схвалення або відхилення) запропонованих посилань. | Must (Обов'язково) |
| **FR-07** | Система має відображати детальну картку ресурсу з текстовим описом та автоматичним прев’ю (скриншотом). | Could (Можливо) |
